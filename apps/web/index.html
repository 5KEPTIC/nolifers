NoLifers Portal

This frontend is powered by Vite and React. If you opened apps/web/index.html directly in Live Server, the app bundle will not load and the page can appear blank.

The expected local workflow is:

  1. Use the built app preview when you are opening this folder through Live Server.
  2. Open a terminal in apps/web and run npm run dev for live React development.
  3. Then open http://localhost:5173.

If you update the React source and want the Live Server preview to match, run npm run build again.
